# social-media---teen-mental-health-python-analysis

Análisis de Redes Sociales y Salud Mental en Adolescentes
Descripción del proyecto

Este proyecto presenta un análisis exploratorio de datos (EDA) sobre el uso de redes sociales en adolescentes y su relación con diferentes variables asociadas al bienestar, incluyendo salud mental, horas de sueño, actividad física, rendimiento académico, interacción social y género.

El análisis fue desarrollado utilizando Python, Pandas y Jupyter Notebook con el objetivo de identificar posibles patrones y relaciones entre las variables del conjunto de datos.

Objetivos
Analizar la distribución del uso de redes sociales entre los adolescentes.
Explorar la relación entre el tiempo dedicado a redes sociales y variables de bienestar.
Evaluar posibles diferencias según género e interacción social.
Practicar técnicas de análisis exploratorio de datos utilizando Python.
Herramientas utilizadas
Python
Pandas
NumPy
Jupyter Notebook
Principales hallazgos
El tiempo promedio de uso de redes sociales fue de aproximadamente 4.5 horas diarias.
No se encontraron relaciones significativas entre el uso de redes sociales y variables como sueño, actividad física, rendimiento académico o interacción social.
Se observó una relación positiva débil entre el uso de redes sociales y los niveles de depresión.
No se identificaron diferencias relevantes en el tiempo de uso de redes sociales entre hombres y mujeres.
Estructura del proyecto
Carga y exploración de datos.
Revisión de tipos de variables y calidad de los datos.
Análisis exploratorio.
Evaluación de correlaciones.
Interpretación de resultados.
Conclusiones finales.
Conclusión

Los resultados sugieren que, dentro de este conjunto de datos, las horas de uso de redes sociales no constituyen un factor determinante para explicar las diferencias observadas en la mayoría de las variables analizadas. Esto resalta la importancia de interpretar los datos de manera objetiva y evitar asumir relaciones sin evidencia estadística.
